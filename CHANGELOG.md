# Изменения

## Обновление 2026-10-17

- Итоговая карточка установщика: адреса панели, действующий логин и пароль,
  цветной вывод в терминале. При обновлении пароль сохраняется; ранее сохранённый
  пароль проверяется по хешу перед показом, для старых установок только с хешем
  выводится пояснение без сброса доступа.
- Политики nftables: TCP/UDP, IPv4/IPv6, Docker DNAT/direct routing.
- Белые списки заменяют общие разрешения портов. Валидация, независимый
  120-секундный откат, подтверждение с проверкой IP, сохранение после reboot.
- Защита действующих SSH-портов и подключённых SSH-клиентов.
- Одна запись домена с несколькими путями и портами Xray, общей заглушкой,
  сохранением старых идентификаторов и хешей паролей.
- Маршруты с точными границами без захвата соседних префиксов.
- HTTP-порт 80 и сохраняемый случайный URL. Backend через Unix-сокет;
  прежний внешний слушатель 8765 удаляется при обновлении сервиса.
- CSRF, Origin, HttpOnly/SameSite, CSP, ограничения тела запроса и памяти.
  Явная смена пароля отзывает сессии.
- Root-owned данные и ограниченные nginx/firewall helper.
- Атомарные ревизии, блокировки, возврат при ошибке nginx, ограничение истории.
- Адаптивный интерфейс в палитре VPN-бота: обзор, домены, Firewall, настройки,
  светлая и тёмная темы, поиск и сортировка.
- Установка через отдельные release-окружения с проверкой backend и восстановлением
  предыдущего кода/настроек при ошибке.
- Первое включение ограничительной сетевой политики требует явного применения
  и подтверждения, чтобы обновление не отключало действующие сервисы без проверки.
